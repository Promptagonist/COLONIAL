# COLONIAL — Manatee County Court Records Archive

## Overview
This repository contains publicly filed court records related to possession
(eviction) actions between Colonial Manor MHC Holdings and named resident
defendants, sourced directly from the Manatee County Clerk of Court's public
records system (manateeclerk.com). It includes per-defendant case PDFs and
compiled timelines documenting the procedural history of each case.

## Source and Legal Basis
All documents in this repository were obtained from the Manatee County
Clerk & Comptroller's Public Records Hub, which provides electronic access
to non-confidential court records under Florida Rule of Judicial
Administration 2.420 and Florida's public records law (Ch. 119, F.S.).
These are official filings in open civil court cases and are, as a matter
of public record, freely accessible to any member of the public.

## What This Repository Is — and Isn't
- This is a **factual archive**, not commentary. No editorial claims,
  allegations, or interpretations are added beyond what appears in the
  original court filings.
- Timelines summarize dates and procedural events **directly from the
  court docket**; they are not opinions about the merits of any case.
- This project does not encourage or condone harassment, contact, or
  targeting of any individual named in these records.

## Data Handling and Redaction
- Documents are posted as retrieved from the Clerk's public portal.
- If any file is found to contain statutorily confidential information
  (e.g., Social Security numbers, financial account numbers, minor
  children's names, or sealed content) that should have been redacted
  under Fla. Stat. § 119.0714 or court order, please open an issue or
  contact the maintainer immediately for removal.
- Individuals named in this repository who wish to request removal or
  correction of a specific record may open an issue with the case number.

## Repository Structure
- `[LASTNAME]-MCCC-[case#]-all.pdf` — full case file for a specific
  defendant/case, sourced from the Clerk's docket.
- `[LASTNAME]-TIMELINE.pdf` — compiled procedural timeline for that
  defendant across all associated case numbers.

## How to Use This Repository

This repository is intended to help readers review publicly filed court
records in an organized, searchable format.

You can use this information to:

- Review the procedural history of a specific case using the case PDF and
  corresponding timeline file.
- Compare filing dates, hearing activity, judgments, writs, and other docket
  events across multiple cases.
- Verify information against the Manatee County Clerk of Court's public
  records system using the case number shown in each filename.
- Conduct research into filing patterns, repeat litigation, case outcomes,
  or recordkeeping over time.
- Preserve access to documents that may otherwise require repeated manual
  searching through the Clerk's portal.

Please use this repository responsibly. The documents are public records, but
they contain information about real people and legal proceedings. This
repository is provided for research, documentation, and verification
purposes only — not for harassment, intimidation, or misuse of personal
information.

## Disclaimer
Use of this repository should remain limited to lawful research,
documentation, reporting, and verification of public court activity. Users
should independently confirm current case status with the Manatee County
Clerk, since court records can change after documents are downloaded.

## Removal Requests
To request review or removal of a specific document, please open an issue
referencing the exact filename and case number.
